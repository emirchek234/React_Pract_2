# Nova Store — React SPA

Учебное одностраничное приложение интернет-магазина на React.

## Технологии
- React
- Vite
- React Router DOM
- Context API и useReducer
- CSS

## Запуск проекта

1. Установите Node.js (если он ещё не установлен).
2. Распакуйте архив и откройте папку `react_shop_spa` в VS Code.
3. Откройте терминал в папке проекта.
4. Выполните команды:

```bash
npm install
npm run dev
```

5. Откройте адрес, который покажет Vite (обычно http://localhost:5173).

Для сборки проекта:

```bash
npm run build
```

## Страницы
- `/` — каталог товаров.
- `/cart` — корзина.
- `/product/:id` — страница отдельного товара.
- `/login` — демонстрационная авторизация.
- `/dashboard` — личный кабинет (доступен после входа).

## Реализованный функционал
- Глобальная корзина через Context API и useReducer.
- Добавление товаров, изменение количества и удаление.
- Автоматический подсчёт итоговой суммы.
- Глобальная светлая и тёмная тема через Context API.
- Сохранение выбранной темы в localStorage.
- Навигация через BrowserRouter, Routes, Route и NavLink.
- Программные переходы через useNavigate.
- Перенаправление на Dashboard после входа и на Login при отсутствии авторизации.
- Поиск и фильтрация каталога.

Вход демонстрационный: подойдут любые непустые имя и пароль. Данные авторизации не отправляются на сервер.
